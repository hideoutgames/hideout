# Hideout

One-page static website for **Hideout** (HAPTIC and Hideout Games), made in Norway by Bru Development ENK. Plain HTML, CSS and a few lines of JS — no build step.

```
index.html            main page
games/index.html      placeholder page for Hideout Games (linked from the Projects tile)
assets/css/style.css  all styles (colour grade, grain, layout, animation)
assets/js/main.js     sets the footer year
assets/img/           photo, glow, logos, wordmark, favicon, social image
.nojekyll             tells GitHub Pages to serve files as-is
```

## Run locally

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

## Deploy on GitHub Pages

1. Push to GitHub.
2. **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Choose branch **main** and folder **/ (root)**, then save.

All links and assets are relative, so the site also works from a project sub-path
(`https://<user>.github.io/hideout/`) before a custom domain is attached.

## Notes

- Font: [Onest](https://fonts.google.com/specimen/Onest) via Google Fonts (`display=swap`).
- Background colour grade is pure CSS (white to #0096ff gradient at 50 % over the photo, plus the blue glow).
- Film grain is generated by the browser (inline SVG `feTurbulence`), static, never baked into an image.
- Animations use transform and opacity only and are disabled under `prefers-reduced-motion`.
- `og:image` / `og:url` assume the site lives at `https://hideout.no/`; adjust in the two HTML files if that changes.
